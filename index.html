What do these mean?

FS starts after it finishes · SS starts when it starts · FF finishes when it finishes · SF finishes when it starts. Lag is in working days; use a minus number to overlap. Greyed-out tasks already wait for this one, so linking them would make a loop.

          How Gantt Planner works

          Every change is kept in this browser straight away, and a backup copy is kept every 5 minutes (see Backups…). To be safe, and to move a project to another computer, use Save to keep a .gantt.json file you can reopen with Open…. Company logo, columns and calendar are saved in the file too.

          • Drag a bar to move it. Drag its right-hand end to change how long it takes.
          • Double-click a row or bar to edit it, including its predecessors (FS, SS, FF, SF and lag).
          • A task with predecessors starts as soon as they allow. Typing a start date or dragging the bar fixes it as “Start no earlier than”.
          • Critical path shows in red the tasks with no float. If any of them slips, the finish date slips.
          • Float is how many working days a task can slip without delaying the end of the project.
          • Calendar… sets working days, UK bank holidays and company closures.
          • From Microsoft Project: in Project, choose File › Save As › XML Format, then use Open… here. Export › Microsoft Project saves a file Project can open.
          • The ◐ button switches between automatic, light and dark.
          • Find and the filter menu show only matching tasks (critical, late, one person’s work…). Shift-click or ⌘-click rows to select several.
          • Constraints, deadlines and “Show on the Timeline” are in the details window. Save a baseline in Layout to compare against later.
